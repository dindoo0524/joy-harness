이 워크시트는 정답을 채우는 시험지가 아니에요. "이렇게 말하면 AI가 알아듣는구나"를 확인하는 참고 카드예요. 우리는 Challenge Log라는 이미 동작하는 앱을 나만의 앱으로 바꾸는 중이에요. 코드를 몰라도, 색상 코드나 영어 단어를 몰라도 괜찮아요 — 내가 원하는 걸 내 말로 AI에게 이야기하면, AI가 코드로 바꿔줘요.

1색상을 요청하는 법

js/config.js의 theme.primaryColor, progressColor가 앱의 포인트 색이에요. #로 시작하는 6자리 코드예요 (예: #2f855a).

색상 코드를 몰라도 괜찮아요. "하늘색으로 바꿔줘"라고 말하면 AI가 알맞은 코드로 바꿔줘요.
빨강 파랑 초록 하늘색 주황 보라 따뜻한 노랑
이렇게 말해보세요 "포인트 색을 하늘색으로 바꿔줘." / "primary color를 주황색으로 바꿔줘."

3js 파일(코드), 이렇게만 알면 돼요

요리에 비유하면 쉬워요. config.js는 내가 꾸미는 곳, CORE AREA는 앱이 움직이는 곳이에요. 나는 config.js부터 바꾸고, CORE AREA는 AI에게 맡겨요.

✔ 내가 꾸미는 곳 — config.js 앱 이름, 문구, 아이콘, 목표 개수, 색상 코드 — 따옴표(" ") 안의 글자, 숫자, #색상 코드는 자유롭게 바꿔도 돼요.
✋ AI에게 맡기는 곳 — CORE AREA storage.js / render.js / guide.js / app.js의 CORE AREA 부분과, config.js의 콜론(:) 왼쪽 이름(예: appName, theme)은 그대로 둬요.

내가 바꾸고 싶은 부분의 이름이 헷갈리면, Alt+G (맥에서는 Option+G)를 눌러보세요. 화면 위에 각 영역의 이름표(data-guide)가 나타나요. 다시 누르면 이름표가 사라져요.

이렇게 말해보세요 "mission-title 글씨를 크게 해줘." / "progress-fill 색을 초록색으로 바꿔줘."

5AI에게는 한 번에 하나씩 부탁해요

한 번에 하나씩 부탁하고, 확인하고, 다음으로 넘어가요.
  1. 한 가지를 부탁해요.
  2. 저장하고 앱에서 확인해요.
  3. 잘 되면 다음 부탁으로 넘어가요.
  4. 안 되면 새 기능을 추가하지 말고 먼저 고쳐요.
✔ 좋은 예시 "앱 이름을 감사노트로 바꿔줘." → 실행 확인 → "포인트 색을 하늘색으로 바꿔줘." → 다시 확인
✋ 좋지 않은 예시 "앱 이름, 색, 아이콘, 버튼, 기능을 한 번에 전부 바꿔줘."
