# 학생 시뮬레이션 결과물 — "감사노트"

`../../starter-project`를 학생이 AI와 대화하며 2주 정도 실제로 써봤다고 가정했을 때, 화면에 어떤 모습으로 나오는지 보여주는 **예시 결과물**입니다. Starter 자체는 건드리지 않았고, 이 폴더만 별도로 복사해서 만들었습니다. 같은 방식으로 만든 다른 예시들은 [`../README.md`](../README.md)에 모아뒀습니다.

`index.html`을 더블클릭하면 바로 확인할 수 있습니다.

## 가상의 학생 시나리오

중학생 학생이 `starter-project`를 열어 다음처럼 AI에게 요청했다고 가정했습니다.

| 학생이 한 말 | AI가 한 일 (`CLAUDE.md` 규칙 적용) | 바뀐 곳 |
|---|---|---|
| "앱 이름을 '감사노트'로 바꿔줘" | 값만 교체 | `config.js` → `appName` |
| "미션 문구를 매일 감사한 일 한 가지 적기로 바꿔줘" | 값만 교체 | `config.js` → `missionTitle`, `missionDescription` |
| "미션 아이콘을 물방울 모양으로 바꿔줘" | 한글 사물 이름 → Material Symbols 이름(`water_drop`)을 AI가 직접 찾아 적용, 학생에게 영어 이름을 되묻지 않음 | `config.js` → `missionImageIcon` |
| "포인트 색을 하늘색으로 바꿔줘" | 정확한 hex 코드를 되묻지 않고 적절한 값(`#38bdf8`)을 AI가 직접 선택 | `config.js` → `theme.primaryColor`/`progressColor` |
| "목표를 14일로 해줘" | 값만 교체 | `config.js` → `targetCount` (7 → 14) |

`storage.js`/`render.js`/`guide.js`/`app.js`(`CORE AREA`)는 전혀 건드리지 않았습니다 — Starter 설계 의도대로, 학생의 요청은 전부 `config.js` 값 교체만으로 끝났습니다.

## "며칠 써온 것"은 어떻게 만들었나

실제로는 `localStorage`에 기록이 하루하루 쌓이지만, 예시를 열자마자 보여주기 위해 `js/demo-seed.js`(이 예시 폴더에만 있는 파일)가 최초 1회 아래 7개 기록을 자동으로 채워 넣습니다. 이번 Starter부터는 기록마다 **체크(완료 표시) 여부**가 따로 있어서, 진행률과 요약 카드 3개는 전부 "체크한 기록"만 셉니다.

- 6일 전, 4일 전, 3일 전, 2일 전, 1일 전, 오늘(1개): 체크 완료
- 오늘 1개 더("이 챌린지 앱을 내가 원하는 대로 꾸며서 뿌듯했다"): 방금 적기만 하고 아직 체크는 안 한 상태

그 결과 화면에는 이렇게 나타납니다.

- **오늘 기록**: 1 (오늘 체크 완료한 것만, 아직 체크 안 한 건 안 셈)
- **남은 도전**: 8 (목표 14 − 지금까지 체크 완료 6)
- **연속 기록**: 5 (오늘부터 거꾸로 하루도 안 빠지고 체크가 이어진 날 수 — 6일 전은 그 사이(5일 전)가 비어 있어 스트릭에 포함되지 않음)
- **진행률**: 6 / 14 완료 (43%)
- 기록 목록에는 7개가 다 보이지만, 아직 체크 안 한 마지막 기록만 동그라미(⭘) 아이콘과 흐린 글씨 없이 표시되고, 나머지 6개는 체크 아이콘(●)과 취소선으로 표시됩니다.

카드 숫자가 진행률 바의 "6/14"와 다른 조합으로 보이는 것은 고장이 아니라 `starter-project/README.md`에 적힌 계산 방식(`오늘 기록`/`남은 도전`/`연속 기록`이 서로 다른 질문에 답하는 지표)대로 동작한 것입니다.

## 이 폴더를 실습에 쓸 때 주의할 점

- 이건 "학생이 이렇게 만들어야 한다"는 정답이 아니라, **Starter를 그대로 두고 몇 가지 요청만 해도 이 정도 결과가 나온다**는 하나의 예시입니다.
- 실제 수업에서 학생에게 보여줄 때는 `js/demo-seed.js`가 있다는 것과, 이 파일은 시연용이라 진짜 Starter(`starter-project`)에는 없다는 점을 먼저 알려주세요.
- 학생이 이 폴더를 복사해서 시작하면 첫 실행에 예시 기록이 자동으로 채워지므로, 빈 화면부터 시작하는 원래 경험을 원한다면 반드시 `starter-project`에서 새로 복사해야 합니다.
- `js/storage.js`의 `STORAGE_KEY`에 `__01-gratitude-note` 접미사를 붙여뒀습니다. 여러 예시를 같은 브라우저에서 연달아 열어봐도 기록이 서로 섞이지 않게 하기 위한 DEMO 전용 조정이며, 실제 Starter의 `STORAGE_KEY`(`challenge-log-records`)와는 다릅니다.
