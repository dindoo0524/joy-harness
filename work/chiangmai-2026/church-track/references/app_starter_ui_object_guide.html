Object Guide

테두리 컬러와 라벨 컬러가 같은 영역을 가리킵니다.

app-logo앱 이름 또는 브랜드 이름
app-badge기간, 상태, 짧은 안내
mission-card현재 미션을 보여주는 큰 카드
mission-category미션 종류 또는 작은 제목
mission-title가장 중요한 미션 제목
mission-description미션에 대한 짧은 설명
progress-section진행률 전체 영역
progress-bar진행률이 채워지는 바탕
progress-fill실제로 채워진 진행률 부분
progress-label현재 진행 상황을 보여주는 숫자
mission-image미션 대표 이미지
summary-card-1~3기록 수, 연속 일수 등 요약 정보
record-input새로운 기록을 입력하는 영역
record-list저장된 기록이 모이는 영역
bottom-nav화면 아래에 고정된 메뉴
btn-home 등각 화면으로 이동하는 하단 버튼
btn-share친구에게 공유하는 버튼
Progress Bar의 컬러는 CSS 변수 --progress-fill 값만 바꾸면 학생이 쉽게 변경할 수 있도록 설계했습니다.
