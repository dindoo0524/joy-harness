# CLAUDE.md — Church Track Starter Kit 수업 중 응답 규칙

이 폴더는 중학생이 AI와 대화하며 이 Starter를 자기 앱으로 바꾸는 실습 중에 쓰인다. 학생 요청에 답할 때 아래 규칙을 따른다.

## 색상 요청

학생이 "하늘색으로 바꿔줘", "따뜻한 주황색으로 해줘"처럼 색 이름으로만 요청하면, 정확한 hex 코드(`#`으로 시작하는 6자리 값)를 되묻지 말고 적절한 값을 직접 골라 `js/config.js`의 `theme.primaryColor`/`progressColor`에 적용한다. 학생에게 코드 값을 알아오라고 시키지 않는다.

## 아이콘 요청

학생이 "물방울 모양", "불꽃 아이콘"처럼 한글 사물 이름으로 요청하면, Material Symbols의 대응 이름(`water_drop`, `local_fire_department` 등)을 직접 찾아 적용한다. 학생에게 Google Fonts 아이콘 사이트에서 영어 이름을 찾아오라고 시키지 않는다.

## "안 눌려요 / 안 움직여요" 같은 버그 신고

코드를 바로 고치기 전에, 먼저 `README.md`의 "시작 전에 먼저 알아두면 좋은 것 (알려진 제한사항)"에 해당하는지 확인한다.

- 해당하면: "그건 고장이 아니라 이번 버전(v0.1)에서 아직 만들지 않은 부분이에요"라고 먼저 알려주고, 대신 할 수 있는 것을 안내한다. 코드를 고치려 하지 않는다.
- 해당하지 않으면: 실제 버그로 보고 원인을 확인해 고친다.

## 공통

- `CORE AREA` 주석이 붙은 함수(`storage.js`/`render.js`/`guide.js`/`app.js`)는 이름과 반환 구조를 바꾸지 않는다. 학생 요청이 이 영역을 건드려야 하는 경우, 함수 내부 로직만 바꾸고 이름은 유지한다.
- 개발 용어(함수, DOM, 배열 등) 대신 학생이 화면에서 본 이름(`data-guide` 값)이나 결과로 설명한다.
