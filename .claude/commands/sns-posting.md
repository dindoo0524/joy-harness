너는 지금부터 "SNS 포스팅 작성 모드"로 동작한다. 이 프로젝트의 인스타그램/페이스북 포스팅 문구를 사용자와 함께 만든다.

## 0. 준비

먼저 아래를 읽어라. 이번 세션에서 이미 읽었더라도, 파일이 변경됐을 수 있으니 다시 읽어라.
- `work/sns-posting/joystyle_style_guide.md` — 문체/구조/해시태그 규칙 (이 문서의 "스타일 요약" 섹션을 그대로 따를 것. 여기 없는 새로운 스타일을 임의로 만들지 마라.)
- `work/sns-posting/history/INDEX.md` — 전체 포스팅 목차 (다음 번호·최근 톤 참고용). 필요하면 표에 링크된 개별 파일도 몇 개 열어서 최근 톤을 확인해라. 전체 히스토리 파일을 다 읽을 필요는 없다.

## 1. 입력 받기

사용자가 `$ARGUMENTS` 로 이미 내용을 줬으면 그걸 초안/키워드로 간주하고 바로 2번으로 넘어가되, 빠진 필수 항목이 있으면 짧게 되물어라.

`$ARGUMENTS` 가 비어 있으면 아래 폼을 제시하고 입력을 기다려라:

```
(필수) 초안: (있었던 일, 사진 설명, 하고 싶은 말을 자유롭게)
키워드: (선택)
강조하고 싶은 포인트: (선택)
플랫폼: 인스타그램 / 페이스북 / 둘 다 (선택, 기본은 인스타그램 기준으로 작성 후 필요시 페이스북용으로 변형)
언어 구성: 자동 판단 / 영어만 / 한국어→영어 / 한국어만 (선택, 기본은 스타일 가이드 기준으로 자동 판단)
```

'초안'은 완성된 글이 아니어도 된다 — 메모, 키워드 나열, 있었던 일 요약 정도면 충분하다.

## 2. 초안 작성

입력받은 내용을 `joystyle_style_guide.md` 의 스타일 요약을 기준으로 가공해서 포스팅 문구를 작성한다:
- 내용 성격(짧은 순간 / 에피소드 / 서사형 마무리 / 커리어)에 맞는 구조 패턴을 고른다.
- 언어 구성(영어만 / 한글→영어 / 한글만)을 내용에 맞게 고른다. 사용자가 명시했으면 그걸 따른다.
- 해시태그는 가이드의 코어 세트를 기본으로 하고, 주제에 맞는 태그를 덧붙인다.
- 이모지는 가이드에 나온 절제된 사용 패턴을 따른다 (남발 금지).
- 톤은 담백한 1인칭, 감정 과장 없이. 사용자가 준 "강조 포인트"는 자연스럽게 녹이되 어색하게 나열하지 않는다.

작성한 초안을 보여준다.

## 3. 피드백 루프

사용자가 수정 요청을 하면 반영해서 다시 보여준다. 이 루프를 여러 번 반복할 수 있다. 매번 새 버전을 제시한 뒤에는 반드시 짧게 묻는다:

> 최종본입니까?

(이미 직전에 물었는데 사용자가 다른 이야기를 하고 있으면 다시 묻지 않아도 된다. 사용자가 수정 요청을 한 경우, 수정한 새 버전을 보여준 뒤 다시 물어라.)

## 4. 확정 및 적재

사용자가 "응", "최종본이야", "그래" 등으로 확정을 명확히 하면, **포스트 1개 = 파일 1개** 원칙으로 적재한다:

1. `history/INDEX.md` 표의 마지막 번호를 확인한다 (다음 번호 = 마지막 + 1, 두 자리로 zero-pad).
2. 올해 연도 폴더가 없으면 만든다: `work/sns-posting/history/<YYYY>/`.
3. 그 폴더 안에 새 파일을 만든다. 파일명: `<YYYY-MM-DD>-<영문-slug>.md` (slug는 내용에서 뽑은 짧은 영문 kebab-case, 예: `2026-07-26-doi-inthanon-hike.md`). 파일 내용 형식:

```
- 날짜: <YYYY-MM-DD>
- 플랫폼: <인스타그램/페이스북/둘 다>
- 제목: <짧은 제목>

---

```
<확정된 본문 그대로>
```
```

4. `history/INDEX.md` 표 맨 아래(주석 줄 위)에 한 줄을 추가한다: `| NN | <날짜> | <플랫폼> | <제목> | \`<YYYY>/<파일명>\` |`
5. 적재를 완료했다고 사용자에게 파일 경로와 함께 짧게 알린다. 확정본 전체를 다시 출력할 필요는 없다 (이미 위에서 보여줬으므로).

확정하지 않은 초안은 절대 적재하지 마라 — `history/` 아래는 실제로 올린/올릴 확정본만 쌓이는 기록이다. INDEX.md 표에 본문 전문을 적지 마라 (목차만).
