지금까지의 대화를 돌아보고 세션 마무리 리포트를 작성한다. 결과물은 두 부분으로 나뉜다: (A) 이 저장소/이 세션 맥락을 아는 사람을 위한 내부용 체크리스트, (B) 이 대화를 전혀 모르는 사람이나 다른 AI(GPT 등)에게 그대로 복사해서 붙여넣어도 이해되는 독립적인 Session Summary.

## 절차

### A. 내부용 — 작업 요약 + TODO 체크리스트

1. 이번 대화에서 실제로 만들거나 수정한 파일, 실행한 주요 명령, 만든 커밋을 시간 순으로 정리한다.
2. `git log`로 이번 세션 중 만든 커밋들을 확인해서 대화 내용과 대조한다.
3. 굵직한 결정/방향 전환이 있었다면 함께 짚는다.
4. `git status`로 커밋되지 않은 변경사항이 있는지 확인한다.
5. 이번 대화 중 "보류", "나중에", "다음에 확인" 등으로 미뤄둔 것이 있었는지 되짚는다.
6. TaskList에 `pending`/`in_progress` 상태로 남은 작업이 있는지 확인한다.
7. `/Users/joy/.claude/projects/-Users-joy-Documents-GitHub-joy-harness/memory/`에 이미 기록된 open item이 있는지 확인한다.
8. 대화 중 사용자에게 질문했지만 아직 답을 못 받은 것이 있는지 확인한다.

출력 형식:

```
## 이번 세션에서 한 일
- ...

## 남은 TODO / 논의거리
- [ ] ...
```

**전부 클리어(Closing Line):** 체크리스트에 오를 만한 항목이 전부 해결됐거나, 사용자가 이미 명시적으로 보류/스킵하기로 확인한 상태라 더 이상 놓친 게 없을 때 — 즉 "완료 또는 사용자가 인지한 채로 미룬" 상태만 남았을 때 — 아래 문구를 그대로 출력한다. 답을 못 받은 질문이 남아있거나, 사용자가 아직 확인 안 한 새 항목이 있으면 이 문구를 쓰지 않는다.
