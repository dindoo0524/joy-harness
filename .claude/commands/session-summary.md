지금까지의 대화를 **이 대화를 전혀 모르는 독자**(다른 AI 포함)가 읽어도 이해할 수 있는 독립적인 Markdown 블록으로 요약한다. 로컬 파일 경로나 "아까 말씀하신 것처럼" 같은 대화 의존적 표현은 쓰지 않는다.

`/wrap-up`의 일부이기도 하지만, 세션 도중 언제든 단독으로도 쓸 수 있다 — 이 경우에도 "이번 세션"은 지금까지의 전체 대화 기준으로 판단한다. TODO 체크리스트나 커밋 상태 확인은 하지 않는다 (그건 `/wrap-up`의 역할).

## 출력 형식

```
# {프로젝트 이름} — Session Summary ({날짜})

## Project
{프로젝트가 무엇인지 2-3문장 — 처음 보는 사람도 이해 가능하게}

## What happened this session
- {핵심만, 5-10줄 이내}

## Key decisions
- {왜 그렇게 결정했는지, 이유 포함}

## Current state
- {지금 뭐가 존재하고 뭐가 동작하는지}

## Open / next steps
- {다음에 뭘 해야 하는지}
```

전체를 code fence로 감싸서, 복사해서 바로 다른 곳에 붙여넣을 수 있는 형태로 출력한다.
