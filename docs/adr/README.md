# Architecture Decision Records (ADR)

이 디렉터리는 Joy Harness의 중요한 설계 결정을 하나씩 기록하는 곳입니다. `docs/product-model.md`가 항상 최신 상태를 반영하는 **살아있는 문서(Living Document)**라면, ADR은 "왜 이렇게 설계했는가"를 그 시점의 맥락과 함께 남기는 기록입니다.

각 ADR은 하나의 중요한 결정만 담습니다.

| ADR-003 | Data Model (ERD, 관계 정의) | *예정* |
| ADR-004 | Agent Architecture (어떤 Agent가 어떤 역할을 하는가) | *예정* |
| ADR-005 | Artifact Lifecycle (Version, Checkpoint, Ready) | *예정* |
| ADR-006 | Rehearsal System | *예정* |
